# Документування використання системи ШІ (AI_USAGE.md)

У цьому документі зафіксовано випадки взаємодії зі штучним інтелектом під час виконання практичної роботи №3.

### 1. Формування простору складності
- **Поставлена задача:** Запропонувати конфігурацію полінома для наочної перевірки явища перенавчання на наборі Car Evaluation.
- **Пропозиція ШІ:** Згенерувати повний поліном 4-го степеня (209 ознак) із необмеженим пошуком.
- **Дія студента:** Відхилено. Експеримент призвів до зависання обчислень через вибухову колінеарність. 
- **Перевірка:** Шкалу переведено на режим взаємодій `interaction_only=True` для d=4 та d=5 (56–62 ознаки), що дозволило відтворити ріст CV RMSE та розриву узагальнення за лічені секунди.

### 2. Синтаксис розрахунку похибки регресії
- **Поставлена задача:** Отримати функцію обчислення RMSE з бібліотеки scikit-learn.
- **Пропозиція ШІ:** Використати `mean_squared_error(y_true, y_pred, squared=False)`.
- **Дія студента:** Змінено. Код завершився з помилкою `TypeError`.
- **Перевірка:** Звірено з документацією останньої версії scikit-learn, де аргумент `squared` було видалено. Розрахунок реалізовано через пряме добування кореня `np.sqrt(mean_squared_error(...))`.

### 3. Інтерпретація відбору ознак Lasso
- **Поставлена задача:** Проаналізувати нульові коефіцієнти, отримані моделлю Lasso.
- **Пропозиція ШІ:** Стверджувати, що занулені ознаки є абсолютно неінформативними у предметній області.
- **Дія студента:** Змінено (уточнено).
- **Перевірка:** Проведено аналіз структури даних. Оскільки ознаки є корельованими мономи одних і тих самих змінних, алгоритм Lasso обирає одного представника групи. Занулення свідчить про надлишковість для конкретної лінійної комбінації, а не про причинну неважливість.
