# Документування використання системи ШІ (AI_USAGE.md)

У цьому документі зафіксовано випадки взаємодії зі штучним інтелектом.

### 1. Вибір метрики та вагового правила kNN
- **Поставлена задача:** Визначити найкращу метрику та схему голосування для класифікатора kNN на даних Breast Cancer.
- **Пропозиція ШІ:** Застосувати евклідову метрику ($p=2$) зі зваженим голосуванням `weights='distance'`.
- **Дія студента:** Відхилено на основі ізольованого факторіального експерименту.
- **Перевірка:** Роздільне тестування показало, що при $k=3$ мангеттенська метрика $L_1$ досягає F1 = 0.9667, тоді як $L_2$ дає 0.9632. Зважування ваг не покращило результат. Прийнято конфігурацію $p=1$, `weights='uniform'`.

### 2. Масштабування для Linear SVM
- **Поставлена задача:** Оцінити необхідність включення scaler у Pipeline для лінійної машини опорних векторів.
- **Пропозиція ШІ:** Пропустити етап масштабування, оскільки лінійна гіперплощина може самостійно компенсувати ваги коефіцієнтів.
- **Дія студента:** Відхилено.
- **Перевірка:** Контрольне порівняння зафіксувало падіння CV F1 з 0.9637 до 0.9398 без нормалізації. Для SVM масштабування є критичним через залежність геометричного відступу від дисперсії координат.

### 3. Налаштування гіперпараметрів RBF SVM
- **Поставлена задача:** Сформувати сітку пошуку для нелінійного ядра RBF.
- **Пропозиція ШІ:** Оптимізувати лише параметр штрафу $C$, залишивши $\gamma$ за замовчуванням.
- **Дія студента:** Змінено та розширено до спільної 2D-сітки.
- **Перевірка:** Побудована теплова карта довела, що при невдалому виборі $\gamma=1.0$ модель повністю втрачає працездатність ($F1 \le 0.056$) при будь-яких $C$. Доведено необхідність одночасного сіткового пошуку $C \times \gamma$.
